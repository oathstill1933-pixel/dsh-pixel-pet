# 鲸鱼娘 · 状态与动画方案

`character.json` 目前是骨架（`draft: true`），每个状态的 `plan` 记着计划帧数和帧率，帧图还没画。
画完一个状态：把帧放进 `sprites/<状态>_NN.png`，填 `frames` 和 `durationsMs`（毫秒 ≈ 1000 / fps），全部状态齐了再删掉 `draft`，然后跑：

```
python runtime/validate.py --strict characters/whale-girl
```

## 形象

- 定稿形象：维护者本地的待机定稿图 `04_GPT定稿_待机v1.png`（不随包发布）。像素版按溟月 / 女仆版公认设定重新绘制，不逐像素描任何参考图。
- 圆滚滚 Q 版，约 2–2.5 头身。
- 视觉焦点：脸、呆毛、鳍耳、尾鳍尖。几乎每个状态都靠这四样做动画。
- 尾巴露出：从身后右下方伸出，末端是横向鲸尾鳍。
- 帧格子 192×208，逻辑像素 K = 2（96×104 个逻辑像素），透明底，不用 `#FF00FF`。
- 饭碗做成独立道具层，干饭 / 等待 / 收工复用。

## 必需状态

| 状态 | 演法 | 帧 / fps |
|---|---|---|
| `idle` | 站立呼吸（身体上下 1 逻辑像素），鳍耳隔几秒轻扇，尾鳍尖在身后慢摆 | 4 / 4 |
| `walk-left` / `walk-right` | 小碎步，尾巴随步伐反向摆，裙摆荷叶边上下翻；左右镜像 | 4 / 8 |
| `waving` | 举手左右摇，鳍耳同步扇，尾巴翘起，眯眼笑 | 4 / 8 |
| `jumping` | 被戳蹦起：蹲 → 起跳 → 最高点呆毛竖直鳍耳炸开 → 落 → 叉腰鼓腮 → 回（单次） | 6 / 8 |
| `failed` | 服务器繁忙：趴着睡，头顶冒 Zzz | 4 / 3 |
| `waiting` | 端着空碗坐着眼巴巴看用户，碗轻晃，偶尔用勺敲碗边 | 4 / 4 |
| `running` | 深度思考：半眯眼、手指抵下巴，头顶「…」气泡偶尔闪过米饭图标，甩头把饭甩掉 | 6 / 6 |
| `review` | 收工：双手捧出冒尖白米饭，眼睛变星星，尾巴快甩（单次） | 8 / 6 |
| `lie` | 像鲸鱼搁浅整个人摊平趴着，尾巴偶尔拍地，头顶小泡泡 | 4 / 2 |

## 特色动作（`act-*`，被显式点名时才播）

| 状态 | 内容 | 帧 |
|---|---|---|
| `act-eat` 干饭 | 掏碗 → 捧到胸前星星眼 → 低头 → 扒一口米粒溅起 → 左腮鼓 → 右腮鼓 → 满足眯眼冒米粒 → 碗里少一截尾巴甩 | 8 |
| `act-puff` 被叫胖炸毛 | 头顶「胖？」→ 一愣呆毛竖 → 炸毛鳍耳张开 → 叉腰跺脚鼓腮 → 扭头哼尾巴挡肚子 | 5 |
| `act-spout` 鲸鱼喷水 | 吸气 → 憋气 → 呆毛后冒 2 格水柱 → 4 格散开 → 水落头上 → 甩头茫然 | 6 |
| `act-tail` 甩尾巴 | 尾巴左 → 中上翘 → 右 → 中 → 叉腰抬下巴 | 5 |
| `act-mirror` 认不出自己 | 举小鲸图 → 歪头 → 自信点头 → 停顿 → 一僵看尾巴 → 捂脸蹲下 | 6 |
| `act-deepsleep` 摸鱼 | 哈欠 → 尾巴卷成枕头 → 侧躺 → 闭眼 → 鼻涕泡一大一小循环 | 6 |

## 注视（可选）

`lookDirections` 现在为空（不跟随鼠标）。要做就做满 16 个方向：0° = 正上，顺时针每格 22.5°，只动眼睛和头部 1–2 逻辑像素。

## 家具

小床模板的 `occupied` 状态图里画的是钻进去的角色本身，所以床图跟角色走：给鲸鱼娘配床时，`occupied` 要画鲸鱼娘睡在床里。
