# 鲸鱼娘动画原图 · Codex v1

日期：2026-11-10。依据 `tools/source/codex/README.md` 的状态定义交付。

## 交付

- 114 张独立 RGBA PNG：23 个状态共 98 帧，另有 16 向注视帧。
- 命名为 `<状态>_<两位帧号>.png`；注视为 `look_00.png` 至 `look_15.png`。
- 原图统一 1536×1536，真透明底。定稿原图没有缩放，增加透明画布后置于 `(141, 250)`，站立脚底线为 `y=1488`。跳跃和拖拽按动作离地；趴睡维持相同地面线。
- `animation-codex-v1.json` 提供帧顺序、逐帧毫秒数和循环标志。跳跃与审阅是单次动作。
- `preview-codex-v1.html` 可看全部动画；`previews-codex-v1/` 是 GIF 和总览。预览全部循环，便于查看；接入引擎时以 JSON 的循环标志为准。

## 基准与制作

只以选中的 `reference.png`（04 定稿）为形象基准。未使用旧桌宠帧或现有 `sprites/` 作为图像输入。

关键姿势由内置 ImageGen 绘制；每次都附带定稿参考图。用户明确同意后，用脚本从定稿和关键姿势派生呼吸、眨眼、尾鳍、手部、嘴型和注视，避免整帧重画。左右走路与左右拖拽分别生成，未水平镜像。

README 与旧 `STATES.md` 的不同之处，以 README 为准：`listening` 是听用户说话，`review` 是检查清单式审阅。未采用先前试画的听歌耳机稿和收工饭碗稿。

- 每个状态都有实际动画差异；循环中重复的回程姿势、说话的半张嘴属于正常复用。
- 详见 `validation-codex-v1.json`。该报告验证的是原图，**不是运行时帧验收**。

## 后续接入

本批是 README 要求的原图交付，尚未转成 192×208，也没有覆盖 `sprites/` 或 `character.json`。

后续按原图网格做取色、对齐和运行帧导入，检查完成后运行包内 `runtime/validate.py --strict`。请区分本批原图导入与原有从 `base.png` 重新派生状态的 `build_frames.py`，避免后者重画并覆盖原图动画的结果。

GIF 仅为预览：只在预览阶段缩小、合成浅色底并使用 GIF 调色板。原图 PNG 保留透明通道，没有为预览而减色。

本地工作交付包另保留生成提示词、关键姿势原图、制作脚本和独立原图校验脚本，可复现本轮结果。
