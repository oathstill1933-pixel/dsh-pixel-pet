# Codex 出图交付规格（鲸鱼娘）

把 Codex 出的原图放在这个目录。这里放原图就行，不需要先做像素化。像素化、对齐网格、收调色板和校验由包内脚本完成。

## 命名
`<状态>_<两位帧号>.png`，例如 `idle_00.png`、`walk-left_03.png`。

## 每张图的要求
- 一张图只画一帧，画一个完整的全身角色，不要拼成 sprite sheet。
- 背景二选一：真透明，或者纯色 #00FF00 绿底，后者由脚本抠掉。
- 画布统一为正方形，例如 1024x1024。角色在画布里的大小和位置每一帧保持一致：脚底落在同一条水平线上，头顶留出余量，给跳跃和呆毛用。
- 形象、配色、比例以 `../reference.png`（04 定稿图）为准，每次生成都带上它作为参考图。
- 只用像素画风，不要渐变、模糊、文字、水印或阴影地面。

## 状态与建议帧数
| 状态 | 帧 | 说明 |
|---|---|---|
| idle | 6 | 呼吸、眨眼、尾巴轻摆，可循环 |
| walk-left / walk-right | 各 4 | 走路循环；right 不要直接镜像，蝴蝶结要保持在原侧 |
| waving | 4 | 挥手 |
| jumping | 6 | 下蹲、起跳、落地，不循环 |
| failed | 4 | 皱眉抿嘴，从身侧掏出红叉牌，举牌后停住（服务器繁忙） |
| waiting | 4 | 等待 |
| running | 6 | 工作中 |
| review | 8 | 检查或审阅，不循环 |
| lie | 4 | 躺下 |
| listening | 4 | 在听用户说话 |
| attentive | 2 | 注意 |
| curl-sleep | 2 | 蜷着睡，用于上床睡觉，不要画床 |
| speaking | 4 | 说话：TTS 出声时循环播放。身体和待机第 1 帧完全一致，只改嘴：闭、半张、全张、半张 |
| drag-left / drag-right | 各 4 | 被鼠标拎着往左或往右拖：双脚离地，身体和尾巴往拖动的反方向甩，表情慌张。right 同样不要镜像 |
| mood-happy / surprised / confused / thinking / sleepy / sad / oops | 各 4 | 七种表情。疑惑时双眼等大、手抵下巴，小问号浮动。oops 是闯祸了（吐舌头、捂嘴或冒汗滴） |

### 视线（look，鼠标跟随用）
16 张单帧，命名 `look_00.png` 到 `look_15.png`。身体和待机第 1 帧一致，只转头和眼睛，看向不同方向：
- 00 看正上方，按顺时针每张转 22.5 度；
- 04 看画面右侧，08 看正下方，12 看画面左侧；
- 中间几张是斜向过渡，例如 02 看右上、06 看右下。

### 统一要求
- 同一状态的各帧，除了要动的部位，其它像素尽量不变，避免播放时整体闪烁；
- 说话帧和看向帧尤其要只改嘴或头，身体一像素都不要动。

可选的招牌动作，参见 `../../STATES.md`：吃米饭等。

交齐一批就通知，由脚本按原图自身的像素格子逐格取色（一格对一像素，不缩放、不减色、不重画），转成 192x208 的帧，并跑 validate。
